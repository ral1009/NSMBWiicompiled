NSMBWCompiled - how to run it
=============================

This is New Super Mario Bros. Wii recompiled to run natively on PC. It contains the game's
code but none of its levels, graphics or sound: those are read from your own copy of the disc.

YOU NEED
- Windows 10 or 11, 64-bit
- A 64-bit CPU with SSE4.2 (Intel 2008 "Nehalem" or newer, AMD 2011 or newer). CPUs with AVX2
  (Intel 2013 "Haswell" or newer, any AMD Ryzen) run the faster build; older ones get a
  compatibility build automatically. That one has not been tested on an older CPU yet - please
  report how it runs.
- A GPU with Direct3D 12 or Vulkan
- Your own dump of the disc: the PAL version (game ID SMNP01, revision 1) or the USA version
  (SMNE01, revision 1). Other versions (Japan, Korea, other revisions) will NOT work.
  An .rvz, .iso or .wbfs file is fine. The USA version is new and less tested than PAL.

SETUP
1. Extract this whole zip to a folder (keep every file together) with ~1 GB free space.
2. Run NSMBWCompiled.exe. The first time, a setup window asks for your game files:
   - "Disc image...": pick your disc image (.rvz, .iso or .wbfs). It is extracted once, into a
     "disc" folder next to the exe (a few seconds; about 350 MB).
     Keep your image outside that "disc" folder: the setup owns it, and versions up to 0.3.0
     deleted an image stored there.
   - "Extracted folder...": pick a folder you already extracted with Dolphin (it contains
     "sys" and "files").
   It shows which version it found (PAL or USA). Optionally install an HD texture pack, then
   press Play. Later launches go straight to the game; hold Shift while starting it to get
   back to this window (another disc, a texture pack). The first launch also builds the shader cache,
   so it can stutter briefly.
   Disc extraction uses DolphinTool.exe from the Dolphin emulator (GPL; see licenses\).

HD TEXTURES (optional)
   The game runs fine without these. Dolphin texture packs for NSMBW work unchanged; none are
   included here because they are made from Nintendo's art - download them from their authors.
   Tested: "NSMBW HD v2.81 (DDS)", and nymo642's HD HUD Tweaks (gamebanana.com/mods/480785).
   The setup window installs one for you ("Install pack...", then pick the pack's folder; hold
   Shift while starting the game to reopen it). To add one by hand instead:
   1. Find the pack's "SMN" folder (the one Dolphin wants in Load\Textures\).
   2. Copy it to  nsmbw_data\texture_replacements\SMN  in this folder
      (create texture_replacements if it isn't there; nsmbw_data appears after the first run).
   3. In the game open Options (F10) > Graphics > "HD texture pack" and turn it on. It switches
      live, and the setting is saved.

CONTROLS (keyboard defaults; any SDL gamepad also works)
   Jump / confirm ..... Z, Space / Z, Enter     Run, fireball / back ... X / X, Backspace
   Spin jump .......... C                       Pause .................. = or Esc
   Move ............... arrow keys
   Tilt the remote .... A / D (gamepad: right stick) - steers tilting platforms
   F10 opens the options menu: graphics, volumes, a controller per player and rebinding.
   Language: F10 > Advanced > Language lists the languages your disc has (PAL: English, French,
   German, Spanish, Italian; USA: English, French, Spanish) and Auto = your Windows language. It
   applies after a restart. By hand: in Config.toml add   [game]   and   language = "fr"
   (en, fr, de, es, it or auto); a language your disc lacks falls back to English.
   The HD texture pack's text pictures are English; in another language those show the disc's own.
   It also opens by itself before the title screen the first time you play.
   Multiplayer: each connected controller is its own player (up to 4); the keyboard is player 1.
   Players can share the keyboard: set a player's controller to Keyboard and bind their own keys.
   Gamepad: Back + Start (- and +) opens the options menu; LB / RB (Q / E) switch its tabs.
   Any binding can be a combination: hold the buttons together while binding.
   Skip the opening cutscene or a hint movie: press - (gamepad: Back) twice.
   The options menu pauses the whole game, sound included.

PAUSE MENU
   Exit works in any course, even one you haven't cleared. Options (also on the world-map
   menu) opens the options menu.

SAVE DATA
   Menu (=) > Save on the world map always saves fully and keeps playing - no Quick Save,
   even before the game is beaten.
   %LOCALAPPDATA%\WiiCompiled\NAND\title\00010004\534d4e50\wiimj2d.sav  (PAL)
   %LOCALAPPDATA%\WiiCompiled\NAND\title\00010004\534d4e45\wiimj2d.sav  (USA)
   The two versions keep separate saves.

IF IT FAILS
   Send nsmbw_data\NSMBWCompiled.log (in this folder; it is rewritten on every launch, so
   copy it before starting the game again), plus your CPU and GPU model. The zip's name
   says which build you have.
